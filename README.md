# CryptoTracker

## Beskrivning
Ett Python-verktyg för att hämta, bearbeta och visa kryptovalutapriser.

## Installation
1. Klona repot: git clone https://github.com/Toldelol/CryptoTracker.git
2. Skapa venv: python -m venv .venv
3. Aktivera venv: source .venv/bin/activate eller .venv\Scripts\activate
4. Installera beroenden: pip install -r requirements.txt

## Körning
python src/main.py
